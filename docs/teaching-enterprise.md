# 教學與企業使用

公開教學：以 VAC 說明「輸入 → 查資料 → 核對 → 解釋」，先示範 2330，再比較 2330 與 2454，最後示範錯誤代號。

課程練習：學員選一檔上市股票，提交報告並指出來源、交易日、擷取時間及一項限制。評量四項：代號正確、時間完整、計算依據清楚、沒有把推論當保證。以是否能說清楚為主，不以漲跌預測評分。

企業內部：由使用者定義需求，維護者記錄版本與依賴，覆核者檢查同日及數據口徑。一般管理任務需更換資料與規則，本 Skill 不直接涵蓋 ISO、人事或營運分析。

討論題：如果個股與大盤日期不同，能比較嗎？如果程式退出碼為零，哪些欄位仍要檢查？如果 README 更動，為何發布雜湊會不一致？
