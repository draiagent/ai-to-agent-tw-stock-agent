# VAC 八步驟文字規格

以本次提供的 assets/tw-stock-agent-vac.png 為圖卡來源，保留圖片內容；文字規格補充驗收界線。

|步驟|任務與規則|
|---|---|
|01 任務理解｜確認查詢目標|精確核對名稱、代號與日期，確認上市股票與比較需求|
|02 行情取得｜連接公開資料|taux-io/twse-mcp 0.15.0 為基準；盤中快照與官方日行情分列，保留來源與時間|
|03 資料驗證｜確認可用性|檢查缺值、過期與日期，缺成交價不用買賣報價補值|
|04 指標計算｜用公式算清楚|twstock 1.5.1＋Python；計算漲跌幅、均線與振幅，量比採官方完整日資料|
|05 價量分析｜解讀市場表現|股票分析 ai-stock-skill 0.1.0；解讀均線與比較市場表現強弱；依據價量與均線，說明判讀理由|
|06 綜合判讀｜區分事實推論|同交易日才能比較市場強弱，分開事實、推論與資料限制|
|07 結果解釋｜輸出清楚報告|行情摘要、分析依據、來源、時間、單位與限制|
|08 QA 交付｜核對再輸出|代號、時間、數字一致；真實、模擬、未驗證分列；錯誤先修正|

第五步警語：過去績效不代表未來績效。
